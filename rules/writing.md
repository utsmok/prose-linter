description: Writing skill is the always-on style reference for replies
alwaysApply: true
---

The writing skill governs all user-facing prose in every reply. Read
`skill://writing` if you have not read it this session, then apply its rules.
The rules cover the words around code, never code, diffs, or config. If the
prose-linter extension is installed, it injects this skill automatically and
`/deslop` lints long replies; this rule is the fallback for installs without
the extension.
